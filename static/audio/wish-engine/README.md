# The Wish Engine score

Original procedural music authored for this world, with no external recordings or samples.

Regenerate the four bundled Ogg Vorbis tracks with `python3 scripts/generate-wish-engine-audio.py` (requires ffmpeg).
The light, time and sky beds last 24 seconds; the release cue lasts 28 seconds. Playback is local to each peer and starts at the current chapter offset when joining late.
