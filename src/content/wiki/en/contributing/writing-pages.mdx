## Adding a page

Every page has an **Edit this page on GitHub** link at the bottom. To add a new one, create a `.md` or `.mdx` file under `src/content/wiki/<locale>`. Folders become sidebar sections and `index.md` is a folder's landing page. Frontmatter supports `title`, `description`, `order` and `draft`. The page title is rendered from the frontmatter, so start the body with `##`.

<Callout type="tip">Svelte components work inside the page — import them at the top of the page.</Callout>

## Translations

Every locale has its own folder (`en`, `es`). A page missing in the active locale falls back to English.
